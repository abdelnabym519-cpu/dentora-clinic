# Changelog — Orthodontic Simulator

All notable changes to this module are documented here.

## [Unreleased]

## [0.1.0] - 2026-08-28

- Added an independently removable, local-only deterministic orthodontic movement sandbox.
- Added FDI identity, explicit millimetre coordinate-frame rules, deterministic staging, transforms, scale checks, movement warnings, provenance digests and optional static proximity checks.
- Added a read-only Dental3D capability boundary that fails closed for whole-arch-only geometry and unavailable trusted tooth-local frames.
- Added Nuxt/Vue + TresJS + Three.js schematic FDI selection with stage, preview and numeric-control UX without copying OrthoViz source code.
- Added Windows x64 Python 3.11/3.12 standalone core compatibility evidence and Apache-2.0 OpenSource Ortho attribution.
- Added backend, Vitest and Playwright safety coverage.
