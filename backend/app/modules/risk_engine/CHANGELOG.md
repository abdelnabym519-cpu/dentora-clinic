# Changelog

## 1.0.0 — 2026-08-25

- Added deterministic observed-fact Risk Engine over CaseSnapshot.
- Added explicit present/absent/not_available/invalid_or_stale factor semantics.
- Added deterministic input/result digests and complete source provenance.
- Added append-only versioned persistence and mandatory dentist accept/reject review.
- Added fail-closed patient-space 3D Risk Map contract with no synthetic geometry.
- Added tenant-scoped/RBAC API for generate, latest/history and review.
- Added focused deterministic, safety, provenance, review and API tests.
- Reused existing Dental3D ThreeUI stack without adding models, weights or dependencies.
